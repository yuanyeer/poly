# poly

通过 [Polymarket](https://polymarket.com) 做预测市场套利。

Polymarket 是基于区块链的预测市场：同一事件可以拆成多个互斥结果（例如 Yes / No），也可以在相关市场之间形成定价关系。当这些结果的隐含概率之和偏离 1、或相关市场定价不一致时，就可能出现无风险或低风险的套利空间。

## 在做什么

本仓库用于发现、计算并执行 Polymarket 上的套利机会，核心方向包括：

- **互补套利**：同一市场内互斥结果的价格之和明显偏离 1
- **跨市场套利**：相关事件、等价表述或逻辑蕴含关系之间的定价不一致
- **价差与对冲**：在流动性允许的前提下，同时买入/卖出一组结果，锁定价差

## 目录

仓库刚初始化，策略、数据抓取、下单与风控代码会陆续补上。

## 风险提示

预测市场价格会快速变化，链上确认、滑点、手续费和流动性都会侵蚀理论价差。任何策略都可能亏损，本项目不构成投资建议。
